Why It Matters The Frame is the top layer of an emerging stack — the project-management scaffold on top of the harness, on top of the model.

By 2026, “use AI for work” is table stakes. The interesting question is what sits around that AI so it stays accountable, ownable, and portable past the original engineer. Three layers, bottom-up: a foundation model that does the thinking, a harness that turns that thinking into tool-use and file-edits, and a project-management framework — the Relay Frame — that holds the work itself in a shape another human (or another agent) can pick up tomorrow morning.

The Relay Frame prevents progress and knowledge assets from being lost over time as roles shift and handoffs occur.

Top · The Frame

Portable handoff scaffold

The Relay Frame. A portable Markdown scaffold (orchestrator + session log + tasklist + skills + people + customizations) wrapped around the project, so the work is transferable, durable, and effortful in the right places.

Middle · Harness

Agentic harness

An interface that turns the model into something that can read files, edit them, and run commands. Today: Claude Code, Wibey, code-puppy, Cursor, etc. The harness gives the model hands.

Foundation · Model

Foundation model

The LLM doing the thinking — Claude, GPT, Gemini, whatever ships next quarter. Strong on its own. Powerful, but stateless and unaware of your project until something tells it where to look.

Suggested Deployment Two ways to put the Frame on a project. Both work; one is faster once you’re used to it.

The Frame is designed to work from scratch in a bare terminal opened on a project folder. Higher efficiency comes from using Wibey inside VS Code, where the file manager and all the deliverable files — code, web pages, documents, spreadsheets — live inside one app alongside the agent.

Beginner · Bare terminal

Terminal + code-puppy or wibey

  1. Download the Relay Frame package into a folder on your machine.
  2. Right-click the folder and choose Open in Terminal (or cd in).
  3. Run code-puppy or wibey in that folder to start chatting with the project.
  4. The agent reads CLAUDE.md on cold start and you’re working.

Zero IDE setup. Anywhere a terminal opens, the Frame works.

Advanced · IDE-native

VS Code + Wibey extension

  1. Open the project folder in VS Code with the Wibey extension installed.
  2. The file manager, the agent chat, and every deliverable file — code, web pages, documents, spreadsheets — live inside one app.
  3. Use the four Frame files (CLAUDE.md, _session_log.md, 00_Master_Tasklist.md, .claude/commands/*.md) directly from the sidebar.
  4. Read, edit, and run from the same window.

Same Frame, one window, no context-switching to a separate terminal or browser.
