Anatomy of the Relay Frame

The exploded view — modules, owner habits feeding each one, and the day-one payoffs a new steward gets when they pick up the frame for the first time.

The four modules Each module is one file (or one folder) plus the owner habit that keeps it fresh. Click to expand the owner habit feeding it and the day-one question it answers.

  1. 01 Cold Start · Claude and project files CLAUDE.md ▸

    The orchestrator the AI reads at session start, plus the project’s scope, data access, and scope-shift history.

    Every rule is scar tissue from a real mistake.

    Owner habit feeding this file

    Capture scar tissue

    “Update your agent-level files with that FEEL script issue and instructions to check it in the future, along with using the colony skills so that error never happens again.”

    Feeds CLAUDE.md + known_issues.yaml + .claude/commands/

    Enables Post Baton-Handoff Motions Like:

    Quick agent & Associate context
    • “Alec told me he’d sorted through the API but he said it was fragile in testing — what did he see that led to that conclusion and was it sorted out?”
    • “Tell me why we did this project.”
    • “Who were the key Associates involved in advising this project?”
  2. 02 Session Log _session_log.md ▸

    Append-only daybook with a fixed six-section format per dated entry.

    A daily work tool, not a handoff doc.

    Owner habit feeding this file

    End-of-day close-out

    “Let’s close out for today — update the session log.”

    Feeds _session_log.md · carries forward into Module 03 (tasklist)

    ✓Session log updated · _session_log.md Session 042 · 2026-05-27 · 6 sections · 84 lines appended · work landed.

    At cold start, /frame-doctor runs alongside the capacity meter (both parallelized, sub-second) and folds an eight-check health summary into the first visible output.

    Enables Post Baton-Handoff Motions Like:

    Best-in-class diagnostic support
    • “The program is sending bad outputs — explain how the confidence engine was originally developed, and start diagnosing what I’m seeing here.”
  3. 03 Master Tasklist 00_Master_Tasklist.md ▸

    Two-tier file — status dashboard above the fold, verbatim receipts below.

    Completed work is swept, never summarized.

    Owner habits feeding this file

    In-the-moment task detail capture

    “Update the tasklist to document why the API feature was scrapped, then sweep it off the main task list.”

    Feeds 00_Master_Tasklist.md + NN_Complete_Sweep_*.md

    Future-state note

    “Long term, the plan for HITL is to use MerchOne, but we aren’t there yet — be sure that detail makes it to that task on the tasklist.”

    Feeds 00_Master_Tasklist.md below-the-fold

    Enables Post Baton-Handoff Motions Like:

    Rapid continued development
    • “Samson’s out all next week — can anyone volunteer to fire up the Relay Frame he had going for the monthly leadership update and run through his deck update path?”
    • “What wasn’t completed in this project, and why?”
    • “Were there future steps or a roadmap flagged to add to this project?”
  4. 04 Custom Skills & Project Files .claude/commands/*.md ▸

    Markdown protocols re-read on every invocation, plus the working files those protocols operate on — all checked into the repo.

    Executable behavior, not narrative.

    Skills resolve two ways. The canonical file lives at its module path (e.g., 02_session_skills/00_session_log_protocol.md) — that’s the spec, harness-portable. A thin shim at .claude/commands/<slug>.md auto-routes Claude Code’s slash-command lookup to the same canonical file. Path-first, shim-second.

    Owner habit feeding these files

    Capture scar tissue

    When a recurring mistake earns a permanent fix, the protocol gets a new canonical skill file at its module path — checked in, re-read every time the command runs — plus a one-line shim at .claude/commands/<slug>.md.

    Feeds 02_session_skills/ (et al.) + .claude/commands/

    Enables Post Baton-Handoff Motions Like:

    Protocol over narrative
    • “Priya hardened /frame-doctor after the deploy bug last quarter — run it now before I commit anything, just like she would have.”
    • “What custom skills exist for this project, and what scar tissue does each one enforce?”
